# Genick-View-Desktop

Player e galeria independente focado na soberania, segurança e privacidade de mídia.

Desenvolvido seguindo as diretrizes e fundamentos do **ID-LACRE**.

## 🚀 Funcionalidades
* Interface nativa construída em PyQt6 no Linux Mint.
* Player de vídeo integrado utilizando fiação lógica dinâmica.
* Totalmente independente, livre de rastreadores e sem dependência de nuvem corporativa.

💻 Instalação via Terminal (Para sistemas baseadas em Debian/Ubuntu/Mint)
Para uma instalação mais fluida, abra o seu terminal na pasta onde você baixou o arquivo .deb e rode o seguinte comando:

sudo dpkg -i genick-view-desktop.deb

Nota: Se o sistema acusar falta de alguma dependência do Python ou do PyQt6 durante a instalação, basta rodar o comando abaixo para corrigir e finalizar automaticamente:

sudo apt install -f
