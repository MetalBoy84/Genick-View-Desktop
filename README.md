# Genick-View-Desktop

Player e galeria independente focado na soberania, segurança e privacidade de mídia.

Desenvolvido seguindo as diretrizes e fundamentos do **ID-LACRE**.

## 🚀 Funcionalidades
* Interface nativa construída em PyQt6 no Linux Mint.
* Player de vídeo integrado utilizando fiação lógica dinâmica.
* Totalmente independente, livre de rastreadores e sem dependência de nuvem corporativa.
